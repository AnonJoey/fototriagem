# Privacy Policy / Política de Privacidade

Last updated / Atualizado em: 2026-11-05

## English

GS PhotoTriage is a personal photo-sorting tool written and used by one person (the developer). The source code is public in this repository.

**What the app accesses.** When the user signs in with Google, the app (and the rclone mount on the user's own computer) asks for access to the user's own Google Drive (scope `drive`). It uses that access only to list, read, move, rename and upload the user's own photo and video files, for example moving a photo to a folder or to a `_lixo/` (trash) folder.

**Where the data goes.** Files and metadata stay between the user's Google Drive and the user's own devices (a PC, a home server and an Android phone on the same network). The developer does not operate any server that receives this data. No file, file name, token or account information is sent to the developer or to any third party. The app does not include analytics, advertising or tracking.

**Optional local service.** The app can talk to an Immich server that the user runs on their own computer. That traffic stays on the user's local network.

**Storage of credentials.** The OAuth token is stored only on the user's own devices (for example in the local rclone configuration file). It is never uploaded anywhere.

**Sharing.** Data is not sold, shared or transferred to anyone.

**Google API Services.** The use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Deleting data and revoking access.** The user can revoke the app's access at any time at https://myaccount.google.com/permissions. Because the developer holds no copy of the data, there is nothing to delete on a server.

**Contact.** followthepillow@gmail.com

## Português

O GS PhotoTriage é uma ferramenta pessoal de triagem de fotos, escrita e usada por uma só pessoa (o desenvolvedor). O código-fonte é público neste repositório.

**O que o app acessa.** Quando o usuário entra com a conta Google, o app (e o mount do rclone no computador do próprio usuário) pede acesso ao Google Drive do próprio usuário (escopo `drive`). Esse acesso só é usado para listar, ler, mover, renomear e enviar os arquivos de foto e vídeo do próprio usuário, por exemplo mover uma foto para uma pasta ou para a pasta `_lixo/`.

**Para onde vão os dados.** Arquivos e metadados ficam entre o Google Drive do usuário e os dispositivos dele (um PC, um servidor doméstico e um celular Android na mesma rede). O desenvolvedor não opera nenhum servidor que receba esses dados. Nenhum arquivo, nome de arquivo, token ou informação de conta é enviado ao desenvolvedor ou a terceiros. O app não tem análise de uso, publicidade nem rastreamento.

**Serviço local opcional.** O app pode conversar com um servidor Immich que o usuário roda no próprio computador. Esse tráfego fica na rede local.

**Credenciais.** O token OAuth fica só nos dispositivos do usuário (por exemplo, no arquivo de configuração local do rclone). Ele nunca é enviado a lugar nenhum.

**Compartilhamento.** Os dados não são vendidos, compartilhados nem transferidos a ninguém.

**APIs do Google.** O uso das informações recebidas das APIs do Google segue a [Política de Dados do Usuário dos Serviços de API do Google](https://developers.google.com/terms/api-services-user-data-policy), incluindo os requisitos de Uso Limitado.

**Apagar dados e revogar acesso.** O usuário pode revogar o acesso do app a qualquer momento em https://myaccount.google.com/permissions. Como o desenvolvedor não guarda cópia dos dados, não há nada para apagar em servidor.

**Contato.** followthepillow@gmail.com
